ІСКЕ ҚОСУ: index.html файлын браузерде ашыңыз (интернет қажет емес).
ОРНЫНДА: 3 концептуалды сурет (assets/images/*-reference.*), 7 нақты видео, кадрлар, галерея, сауалнама, эко-тест, ойындар.
ЖОҚ (нақты ресурстар қажет): Three.js/Babylon.js кітапханалары (assets/libs), GLB модельдер (assets/models/*), табиғи су дыбысы (assets/audio).
Қазіргі 3D-көріністер — жалпақ концептуалды суреттегі интерактивті нысандар, нақты 360° 3D модель емес.

3D саяхат: интернет және WebGL қажет (Three.js CDN). Карта — концептуалды модель.
